# Limber

![Limber](assets/limber.png)

**Limber** — нагадування про перерви для Windows: «час розім'ятися».

- Надійний таймер: не скидається через неактивність чи блокування екрана; час сну не зараховується.
- Міні-перерви з вправами для очей, шиї, рук (і для тіла — на вищих рівнях).
- Довга перерва як інтервальне тренування: розминка → вправи 40 с / відпочинок 15 с → заминка.
- Три рівні інтенсивності: легко, середньо, енергійно.
- Нагадування пити воду з порадами та денною метою склянок.
- Статистика за 7 днів, повзунки налаштувань, демо-перегляд вікон.
- Іконка-кільце в треї показує, скільки лишилося до перерви.

## Встановлення

Завантажте `LimberSetup-<версія>.exe` зі сторінки **Releases** і запустіть.
Права адміністратора не потрібні — програма ставиться в `%LOCALAPPDATA%\Programs\Limber`.

> Інсталятор не підписаний, тож Windows SmartScreen може попередити:
> «Докладніше» → «Однаково запустити».

Під час встановлення можна увімкнути **автозапуск** (завдання «Limber» у Планувальнику
завдань — стартує через 20 с після входу в систему) та ярлик на Робочому столі.
Автозапуск також перемикається в програмі: «Налаштування» → «Інше».

Дані користувача (налаштування, статистика, журнал `limber.log`) зберігаються в
`%APPDATA%\Limber` і лишаються після видалення програми.

## Розробка

Потрібні Python 3.12 і (для інсталятора) [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```powershell
python -m pip install -r requirements.txt -r requirements-build.txt
python src\limber.py --open   # запуск із коду
python -m pytest -q           # тести
.\build.ps1                   # dist\Limber\Limber.exe + dist\LimberSetup-<версія>.exe
```

## Випуск нової версії

1. Змініть `__version__` у `src/limber.py`.
2. Закомітьте й поставте тег:

   ```powershell
   git tag v1.0.1
   git push origin main --tags
   ```

3. GitHub Actions збере інсталятор і опублікує його в Releases.

## Структура

| Шлях | Що це |
|---|---|
| `src/limber.py` | уся програма |
| `assets/` | іконка (генерується `tools/make_icon.py`) |
| `installer/limber.iss` | сценарій інсталятора Inno Setup |
| `build.ps1` | збирання exe та інсталятора |
| `tests/` | тести логіки таймера й тренувань |
| `.github/workflows/release.yml` | збирання в CI та публікація релізів |
