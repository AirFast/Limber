# Rhythmos

![Rhythmos](assets/rhythmos.png)

**Rhythmos** (від грец. ῥυθμός — «ритм, лад») — нагадування про перерви для Windows і macOS: «ритм здорового дня».

До версії 2.0 програма називалась **Limber**; налаштування, статистика й автозапуск переносяться автоматично.

- Надійний таймер: не скидається через неактивність чи блокування екрана; час сну не зараховується.
- 81 вправа в шести групах (очі, шия й плечі, спина, руки, ноги, усе тіло); на екрані перерви можна вибрати групу
  (кнопки груп вимикаються в налаштуваннях — тоді вправи просто випадкові).
- Вибір звуку сповіщення із системних звуків, з прослуховуванням.
- Повідомлення про нові версії (раз на добу перевіряє GitHub Releases).
- Довга перерва як інтервальне тренування: розминка → вправи 40 с / відпочинок 15 с → заминка.
- Три рівні інтенсивності: легко, середньо, енергійно.
- Нагадування пити воду з порадами та денною метою склянок; норма «Жінка» / «Чоловік» за рекомендацією EFSA
  сама задає мету й інтервал (або «Вручну» — повзунками).
- Статистика за 7 днів, повзунки налаштувань, демо-перегляд вікон.
- Іконка-кільце в треї показує, скільки лишилося до перерви.
- Українська та англійська мови: мова з інсталятора, перемикач у «Налаштування» → «Інше».

## Встановлення

Завантажте `RhythmosSetup-<версія>.exe` зі сторінки **Releases** і запустіть.
Права адміністратора не потрібні — програма ставиться в `%LOCALAPPDATA%\Programs\Rhythmos`.

> Інсталятор не підписаний, тож Windows SmartScreen може попередити:
> «Докладніше» → «Однаково запустити».

Під час встановлення можна увімкнути **автозапуск** (завдання «Rhythmos» у Планувальнику
завдань — стартує через 20 с після входу в систему) та ярлик на Робочому столі.
Автозапуск також перемикається в програмі: «Налаштування» → «Інше».

Дані користувача (налаштування, статистика, журнал `rhythmos.log`) зберігаються в
`%APPDATA%\Rhythmos`.

Видалити програму: меню «Пуск» → «Rhythmos» → «Видалити Rhythmos» або «Програми й засоби».
Під час видалення можна вибрати, чи стерти також налаштування й статистику
(за замовчуванням вони лишаються й відновляться після повторного встановлення).

## macOS (Apple Silicon)

1. Завантажте `Rhythmos-<версія>-macos-arm64.dmg` зі сторінки **Releases**.
2. Відкрийте dmg і перетягніть **Rhythmos** у папку **Applications**.
3. Перший запуск: програма не підписана сертифікатом Apple, тож macOS її заблокує.
   Відкрийте **Системні параметри → Конфіденційність і безпека**, внизу натисніть
   **«Усе одно відкрити»** біля повідомлення про Rhythmos і підтвердіть.
4. Rhythmos живе в рядку меню (іконка-кільце вгорі праворуч), у Dock його немає.
   Під час першого запуску вмикається автозапуск — macOS покаже сповіщення
   «Додано фоновий елемент». Вимкнути: «Налаштування» → «Інше».

Видалити: вимкніть автозапуск у налаштуваннях, вийдіть з Rhythmos і перенесіть
його з Applications у кошик. Дані — у `~/Library/Application Support/Rhythmos`.

## Розробка

Потрібні Python 3.12 і (для інсталятора) [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```powershell
python -m pip install -r requirements.txt -r requirements-build.txt
python src\rhythmos.py --open   # запуск із коду
python -m pytest -q           # тести
.\build.ps1                   # dist\Rhythmos\Rhythmos.exe + dist\RhythmosSetup-<версія>.exe
```

## Випуск нової версії

1. Змініть `__version__` у `src/rhythmos.py`.
2. Закомітьте й поставте тег:

   ```powershell
   git tag v1.0.1
   git push origin main --tags
   ```

3. GitHub Actions збере інсталятор і опублікує його в Releases.

## Структура

| Шлях | Що це |
|---|---|
| `src/rhythmos.py` | програма |
| `src/i18n.py` | переклади: інтерфейс, вправи, поради (uk, en) |
| `assets/` | іконка (генерується `tools/make_icon.py`) |
| `installer/rhythmos.iss` | сценарій інсталятора Inno Setup |
| `src/system.py` | усе, що залежить від ОС: автозапуск, монітори, звуки, трей (Windows, macOS) |
| `build.ps1` | збирання exe та інсталятора (Windows) |
| `build_mac.sh` | збирання Rhythmos.app і dmg (macOS) |
| `tests/` | тести логіки таймера й тренувань |
| `.github/workflows/release.yml` | збирання в CI та публікація релізів |
